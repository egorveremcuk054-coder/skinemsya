# Скинемся 💸

Сервис для дележа общих расходов в компании: поездки, общие покупки, съёмная квартира.
Записываете, кто за что платил, а сервис считает, кто кому должен,
и предлагает **минимальное число переводов**, чтобы рассчитаться.

## Как это работает

Поездка в Питер, трое участников:

- Аня оплатила жильё — 6000 ₽ на всех;
- Борис оплатил бензин — 3000 ₽ на всех.

Если считать «в лоб», получится 4 перевода. Сервис считает балансы:

| Участник | Заплатил | Доля | Баланс |
|----------|---------:|-----:|-------:|
| Аня      | 6000     | 3000 | +3000  |
| Борис    | 3000     | 3000 | 0      |
| Вика     | 0        | 3000 | −3000  |

И предлагает **один** перевод: Вика → Аня, 3000 ₽.

### Алгоритм

1. Баланс каждого = сколько заплатил − сколько должен.
2. Берём самого большого должника и самого большого кредитора.
3. Должник переводит кредитору меньшую из двух сумм.
4. Повторяем, пока все балансы не станут нулевыми.

Жадный алгоритм укладывается максимум в `n − 1` перевод для группы из `n` человек.

## Стек

- Java 21
- Spring Boot 4
- Maven

## План

- [x] **Этап 0.** Каркас проекта
- [ ] **Этап 1.** Ядро на чистой Java: деньги, траты, балансы, алгоритм переводов, тесты JUnit
- [ ] **Этап 2.** REST API и PostgreSQL: группы, участники, траты, балансы, миграции Flyway
- [ ] **Этап 3.** Пользователи: регистрация, вход по JWT, доступ только к своим группам
- [ ] **Этап 4.** Docker Compose, Swagger, Testcontainers, CI на GitHub Actions
- [ ] **Этап 5.** Бонусы: валюты, Telegram-бот, точный алгоритм для малых групп, фронтенд

## Запуск

Нужен JDK 21.

```bash
./mvnw test             # тесты
./mvnw spring-boot:run  # запуск приложения на http://localhost:8080
```

На Windows вместо `./mvnw` используйте `mvnw.cmd`.
